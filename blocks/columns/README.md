# columns

Custom **columns** block. Purpose: Alternating image and text rows (image-with-content).

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: one row; cells in visual order. image-with-content left = [picture | H2 + paragraphs], right = [H2 + paragraphs | picture]; without an image a single [H2 + paragraphs] cell.

## Supported variations

| Variation | Option class |
| --- | --- |
| Image with content | `image-with-content` |
| Image left | `left` |
| Image right | `right` |
