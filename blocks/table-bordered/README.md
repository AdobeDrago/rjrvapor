# table-bordered

Custom **table** block. Purpose: Data tables for ingredient and constituent disclosures.

## Authoring (Document Authoring)

Model: `standalone`

Single block table. Content: each block row is a table row and each cell a table cell; the first row is the header unless 'no-header' is set.

## Supported variations

| Variation | Option class |
| --- | --- |
| No header row | `no-header` |
